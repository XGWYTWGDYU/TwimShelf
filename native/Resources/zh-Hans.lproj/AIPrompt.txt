# TwimShelf — AI 打标签的默认提示词（简体中文）
#
# 以 # 开头的行是注释。分段：[system] 系统指令 · [prompt] 每张图片的提问 ·
# [existing] 已有标签，{existing} 会被替换 · [vocabulary] 资料库标签，{tags} 会被替换 ·
# [context] 帖子文字，{text} 会被替换（已去掉 @提及 和链接，最多 300 字；没有正文时不发送）。
# 这里只是默认值，可以在 App 的「AI 模型 → 提示词」里编辑。无论怎么写，程序只会从回答里
# 提取 JSON 字符串数组作为标签。

[system]
你是一个图片标注器。你只输出 JSON 字符串数组，不输出任何其他文字。

[prompt]
为这张图片生成 5 到 10 个简短的中文标签，每个标签 1 到 6 个字，涵盖主体、人物特征、动作、场景、颜色、风格和画面类型（照片/插画/截图等）。只输出 JSON 字符串数组，例如 ["猫","白墙","室内","插画"]。

[existing]
这张图片目前已有的标签（可能来自你或之前的模型）：{existing}
这些标签如果仍然符合图片，请保留原词；不合适的不要输出。

[vocabulary]
资料库里已经在用的标签如下（按使用次数排序）。描述同一事物时，必须直接使用其中的原词，不要另造近义词或换说法（例如已有「白墙」，就不要写「白色墙壁」）；只有没有合适的已有标签时，才新建标签：
{tags}

[context]
这张图片来自一条帖子，帖子文字如下，仅供参考（可能与图片无关；标签应以图片内容为主，可以补充文字中明确提到、且与图片相符的角色名、作品名或主题）：
{text}
