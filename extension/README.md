# TwimShelf 下载器（Chromium 扩展）

在 X 的每条帖子旁加一个下载按钮，点一下就交给已绑定的 TwimShelf 设备下载，并一直跟踪到完成。可以绑定：

- Windows、Linux、macOS 上的 TwimShelf App（Flutter 版和原生版），App 打开时接收；
- TwimShelf Linux 服务器（Docker），随时接收。

这是一个独立的项目，和主项目没有关联：没有构建步骤，构建脚本和 `config.yaml` 都不处理它。

## 安装

1. 在 Chrome、Edge 或其他 Chromium 浏览器（116 以上）打开 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选择这个 `extension` 目录。

更新代码后，在同一页面点扩展卡片上的刷新按钮。

## 绑定设备

在 TwimShelf 里打开「设置 → 浏览器扩展 → 绑定浏览器」，App 会显示一个 6 位绑定码和一段绑定文本。然后点扩展图标：

- **同一台电脑上的 App**：输入 6 位绑定码。扩展会把它交给这台电脑上所有打开的 TwimShelf，只有正在显示这个码的那个会接受。
- **其他电脑或 Linux 服务器**：复制「绑定文本」粘贴进去，粘贴后自动绑定。绑定文本里带着设备的地址。
- **地址不通时**（不同网络、VPN）：展开「通过地址连接设备」，填写 `主机:端口`，再输入绑定码。

绑定码只能用一次，10 分钟内有效，输错 5 次就作废。扩展会列出这台电脑上打开的 TwimShelf，并标明是原生 App、Flutter 版还是服务器，方便区分同名的设备。

## 使用

打开 X，每条帖子的操作栏里，书签和分享按钮旁边会多一个下载按钮：

- 只绑定了一台设备，或者设了默认设备：点一下直接发送。
- 绑定了多台：点按钮会弹出菜单，选择发给哪一台。右键始终弹出菜单。
- 按钮显示进度：发送中、排队中、下载中、已下载、失败。失败时把鼠标移到按钮上能看到原因，再点一次重试。
- 设备离线（App 关着、电脑睡眠）时，任务显示「设备离线」，设备回来后自动发送，最多等 7 天。

扩展图标上的数字是还没完成的任务数，弹出面板里能看到最近的下载、重试失败的任务、设置默认设备、解除绑定。

## 接口

扩展和设备之间的协议在 `core/src/extension.rs`：

| 请求 | 用途 |
| --- | --- |
| `GET /ext/hello` | 是否是 TwimShelf、设备名、平台、是否已绑定 |
| `POST /ext/pair {code, name}` | 用绑定码换取令牌 |
| `POST /ext/download {url}` | 把帖子加入下载队列 |
| `POST /ext/status {urls}` | 查询任务状态 |
| `POST /ext/unbind` | 解除绑定 |

桌面版 App 监听 27800–27809 端口，只接受本机和局域网的请求；Linux 服务器在自己的端口（默认 2778）下提供 `/ext/`。网页无法调用这些接口：带网页来源的请求会被拒绝。
